Her Wellness – Women Health Virtual Assistant

Her Wellness is an AI-powered web application designed to provide personalized health guidance and wellness support for women.

Features
AI Health Assistant
Women Health Assessment
AI Diet Planner
Health and Routine Tracker
Weekly Health Score
Progress Analytics Dashboard
Drug Side Effect Analysis
OTP and JWT Authentication
Multi-language Support
Tech Stack
React.js
TypeScript
Vite
Tailwind CSS
Node.js
Express.js
MongoDB Atlas
Python
Scikit-learn
OpenRouter AI
Redis
AWS
Docker
Vercel

Random Forest Classifier
Label Encoding
One-Hot Encoding
Scikit-learn
Installation
git clone <repository-url>
cd HER-WELLNESS-MAIN
npm install
npm run dev

Create a .env file and add the required API keys and database credentials.

Deployment
Frontend: Vercel
Backend: AWS
Database: MongoDB Atlas
AI: OpenRouter
Cache: Redis
